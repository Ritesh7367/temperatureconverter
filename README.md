# 🌡️ Temperature Converter

A simple and user-friendly web application that converts temperatures between **Celsius, Fahrenheit, and Kelvin**. Built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Click here to use the Temperature Converter](https://Ritesh7367.github.io/temperatureconverter/)

> Note: The live demo will work once GitHub Pages is enabled for this repository.

## ✨ Features

- 🌡️ Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- ⚡ Instant temperature conversion.
- 🎨 Simple and user-friendly interface.
- 📱 Responsive design for different screen sizes.
- ✅ Input validation for a better user experience.

## 🛠️ Technologies Used

- **HTML5** — Structure of the application.
- **CSS3** — Styling and layout.
- **JavaScript** — Temperature conversion logic and interactivity.

## 📐 Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius to Fahrenheit | `(°C × 9/5) + 32` |
| Fahrenheit to Celsius | `(°F − 32) × 5/9` |
| Celsius to Kelvin | `°C + 273.15` |
| Kelvin to Celsius | `K − 273.15` |
| Fahrenheit to Kelvin | `(°F − 32) × 5/9 + 273.15` |
| Kelvin to Fahrenheit | `(K − 273.15) × 9/5 + 32` |
